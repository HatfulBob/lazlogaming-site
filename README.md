# Lazlo Gaming Website

Official website for Lazlo Gaming Ltd, rebuilt with React and Vite.

## About

This is a React-based website showcasing Lazlo Gaming's games and providing information about the indie game development studio.

## Development

### Prerequisites
- Node.js 20 or higher
- npm

### Setup
```bash
npm install
```

### Running locally
```bash
npm run dev
```

### Building for production
```bash
npm run build
```

### Preview production build
```bash
npm run preview
```

## Deployment

The site is automatically deployed to GitHub Pages when changes are pushed to the `main` branch.

The deployment workflow builds the React app and publishes it to GitHub Pages.

## Technologies Used

- React 19
- Vite 7
- React Router
- GitHub Pages for hosting
